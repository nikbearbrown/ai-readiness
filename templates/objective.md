Rules:

- Name AI explicitly. "Use technology effectively" does not meet E2.
- Name the thinking, not the tool. "Use ChatGPT to summarize" is a tool skill; "audit an AI summary for omitted risk factors against the source paper" is an objective.
- Make it assessable in this module: the end-of-module exercise or Assessment should test it.

Example (constructed, algorithms course, module on graph reductions):
*Judge whether an AI-generated NP-hardness reduction proves the direction it claims, before checking both directions by hand.*
